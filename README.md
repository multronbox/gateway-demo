# AI Gateway 示範 — 一鍵試玩版

呢個係一個「多模型 API Gateway」嘅示範版。Gateway 係咩？你可以當佢係一個**總機**：公司入面唔同嘅 AI 工作（傾偈問答、生圖、寫程式），唔使逐個去搵唔同嘅 AI 供應商，只要打去呢個總機，佢會按工作性質，自動分流去最合適嘅 AI 模型，再將結果送返嚟。好處係：公司只管一條線、一組通行證、一個用量紀錄，唔使每個部門各自開一堆帳戶。

## 呢個示範會俾您睇到啲咩

1. **分流決定**：每交一個工作俾 Gateway，佢會話返俾您知——呢件工作會交俾邊個供應商、邊個模型、同埋點解咁揀（例如：文字工作行 Gemini 係因為快同平；生圖行 Gemini 專線；寫程式設計上行 Claude）。
2. **通行證同限速機制**：正式版要用通行證（token）先入到嚟，仲有每分鐘用量上限，防止濫用；示範版會將呢啲機制點運作展示出嚟（見下面「關於通行證」）。
3. **用量紀錄**：每一次呼叫，伺服器都會記低「咩工作、用咗邊個模型、成唔成功」，方便日後對數同管理（紀錄唔會記低您輸入嘅全文，更加唔會記任何密碼或金鑰）。

> **老實講明**：呢個係**示範模式**，所有 AI 回覆都係**模擬**嘅——佢會展示「會分流去邊」同「回覆大概會點樣」，但唔會真係呼叫任何 AI 模型，所以唔會產生任何費用。正式版會用返完全一樣嘅分流邏輯，改為接駁真模型出真結果。

## 一鍵試玩（GitHub Codespaces）

唔使喺自己部電腦裝任何嘢，喺瀏覽器就玩到：

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/multronbox/gateway-demo)

1. 撳上面個掣（或者開 https://codespaces.new/multronbox/gateway-demo ），用 GitHub 帳戶登入。
2. 撳「Create codespace」，等大約一兩分鐘——系統會自動裝好所需軟件，同埋自動啟動示範服務。
3. 畫面下方會彈出一個轉發咗嘅網址（port 8000），撳入去就係服務嘅入口；跟住下面三個例子試就得。

## 三個例子（複製貼上就試到）

喺 Codespaces 入面開一個終端機（Terminal），逐個貼嚟試。將下面嘅 `http://127.0.0.1:8000` 換成您嗰個轉發網址都得。

### 例一：健康檢查 — 服務有冇開著？

```bash
curl http://127.0.0.1:8000/health
```

您會見到類似：`{"ok": true, ..., "demo_mode": true}`。呢個係俾系統管理員隨時確認「部機仲行緊、而家係咩模式」嘅基本檢查。

### 例二：文字工作 — 睇分流決定

```bash
curl -X POST http://127.0.0.1:8000/v1/run \
  -H "Content-Type: application/json" \
  -d '{"task":"chat","prompt":"幫我將呢段公司簡介改寫得親切啲"}'
```

回應入面會有 `routing` 一欄，寫明呢件文字工作會交俾 **Google Gemini** 同原因；`response` 就係模擬回覆。呢個例子示範 Gateway 最核心嘅價值：**工作性質一入嚟，分流即刻有決定，仲有理由睇得返**。

### 例三：生圖工作 — 睇另一條專線

```bash
curl -X POST http://127.0.0.1:8000/v1/run \
  -H "Content-Type: application/json" \
  -d '{"task":"image","prompt":"一隻銀色機械人喺台北街頭","size":"1K"}'
```

呢次 `routing` 會指出行 **Gemini 生圖專線**。示範模式唔會真係生圖（唔使錢、唔使等），只會話您知正式版會點做。

（仲有一個任務類型 `task":"code"` 可以試：設計上會分流去 Claude，不過貴公司目前未訂閱 Claude，示範會如實講明呢條路暫停緊——Gateway 唔會扮做到。）

## 關於通行證（點解示範唔使入密碼）

正式版入面，每個呼叫都要帶一組通行證（gateway token），冇證或者錯證會即刻被拒（回 401），仲有每分鐘次數上限。為咗等您第一次試玩唔會卡喺「冇通行證」嗰步，**示範模式特登將通行證檢查跳過**，但限速機制仍然保留。正式部署嗰陣，只要將示範模式關閉，通行證檢查就會即刻恢復，唔使改任何程式。

## 示範同正式版嘅分別（一表睇清）

| | 示範版（呢個） | 正式版 |
| --- | --- | --- |
| AI 回覆 | 模擬，標明 `simulated: true` | 真模型即時回覆 |
| 費用 | 零（冇呼叫任何供應商） | 按用量計（例如生圖約 US$0.03–0.07／張） |
| 通行證 | 跳過檢查，方便試玩 | 必須帶正確通行證 |
| 部署位置 | GitHub Codespaces（臨時試玩環境） | 貴公司嘅雲端伺服器（常駐運作） |

## 檔案說明（俾技術同事）

- `app.py` — Gateway 本體（FastAPI）：`GET /health`、`POST /v1/run`、`POST /v1/image`、token 驗證、rate limit、用量 log（`usage.jsonl`）。示範模式由環境變數 `DEMO_MODE=1` 開啟，邏輯集中喺 `_demo_route`，非示範路徑同原骨架一致。
- `.devcontainer/devcontainer.json` — Codespaces 設定：開機自動 `pip install`、轉發 port 8000、自動以示範模式啟動服務。
- `.env.example` — 正式部署先需要嘅環境變數清單。**本 repo 唔包含任何真金鑰或通行證**；真 key 只會放喺正式部署環境，唔會入 repo、唔會入 log。
- 正式版仲差一步先接通真生圖：Gemini 嗰段 provider 呼叫要喺動工時對返 Google 當時嘅官方文件同 model ID 先寫，骨架而家會如實回 501，唔會扮成功。
